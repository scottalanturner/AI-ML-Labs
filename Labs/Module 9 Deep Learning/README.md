# Neural Network Playground

An interactive Jupyter notebook exploring how neural networks learn through hands-on experiments. The notebook contains three interactive demonstrations:

1. **MNIST Digit Recognition** - Watch a neural network learn to recognize handwritten digits
2. **Overfitting Demonstration** - Compare simple vs. complex models
3. **Decision Boundaries** - Visualize how neural networks separate data
